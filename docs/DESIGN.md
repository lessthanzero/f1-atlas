# Design notes

- Table first, dashboard second.
- Typography is part of the product.
- Visual refs: biathlontime (density), allekinos (index clarity), otoplenie-tula (one job / search-first).
- Avoid purple gradients, cream+terracotta clichés, broadsheet pastiche.

## Micro-visualisations (shipped)

- **Career finish sparkline** — driver page.
- **Grid → finish slopegraph** — race page (field) and driver page (recent classified starts).
- **Reliability strip** — race field by grid; driver career window with win/podium/points/finish/DNF cells.
